# AcrossView 프레젠테이션 스켈레톤

> 해커톤 주제: **연결**
> 발표 시간: 5분
> 구조: 문제 → 솔루션 → 데모 직관형

---

## 슬라이드 구성 요약

| # | 슬라이드 | 시간 | 핵심 메시지 |
|---|----------|------|-------------|
| 1 | 타이틀 | 10초 | AcrossView - 관점을 연결하다 |
| 2 | Hook | 25초 | "같은 뉴스, 다른 세상" |

## 슬라이드 1: 타이틀 (10초)

### 비주얼 디자인
- **배경**: 어두운 네이비/다크 그레이 (#1a1a2e)
- **중앙**: 로고 + "AcrossView"
- **서브타이틀**: "관점을 연결하다"
- **우하단**: 팀명, 날짜
- **애니메이션**: 로고 페이드인 → 서브타이틀 슬라이드업

### 대본
```
안녕하세요, AcrossView 팀입니다.
저희는 오늘 '연결'에 대해 이야기하려 합니다.
```

---

## 슬라이드 2: Hook (25초)

### 비주얼 디자인
- **레이아웃**: 화면 분할 (50:50)
- **왼쪽**: 스마트폰 목업 - 진보 성향 뉴스 피드
- **오른쪽**: 스마트폰 목업 - 보수 성향 뉴스 피드
- **중앙 오버레이**: 빨간 X 또는 끊어진 선 아이콘
- **하단 텍스트**: "같은 이슈, 완전히 다른 현실"
- **색상**: 대비되는 파랑/빨강 틴트

### 대본
```
두 사람이 같은 날 같은 뉴스를 봅니다.
하지만 완전히 다른 세상을 보고 있습니다.

알고리즘이 각자가 원하는 것만 보여주기 때문입니다.
우리는 더 많은 정보를 접하지만,
서로 다른 생각과의 '연결'은 점점 사라지고 있습니다.
```

## 슬라이드 3: 문제 정의 - 필터버블과 단절 (45초)

### 비주얼 디자인
- **메인 비주얼**: 버블 안에 갇힌 사람 일러스트 또는 아이콘
- **키워드 강조**: "필터 버블" + "확증 편향" (크게)
- **하단 3개 아이콘 카드**:
  - 📺 유튜브: "같은 정치 성향만 추천"
  - 📰 네이버 뉴스: "클릭한 논조만 노출"
  - 💬 커뮤니티: "같은 입장만 보임"
- **색상**: 각 버블이 분리된 느낌 (회색 배경에 고립된 컬러 버블)

### 대본
```
이것이 '필터 버블'입니다.
알고리즘이 내 취향에 맞는 정보만 보여주고,
다른 관점은 아예 보이지 않게 만드는 구조입니다.

유튜브는 시청 기록 기반으로 비슷한 영상만 추천하고,
네이버 뉴스는 클릭 패턴에 따라 같은 논조만 보여줍니다.
커뮤니티에서는 반대 의견 자체가 사라집니다.

결과적으로 우리는 각자 다른 현실에서 살게 됩니다.
서로 연결되지 않은 '병렬 우주'처럼요.
```

## 슬라이드 4: 기존 솔루션의 한계 (30초)

### 비주얼 디자인
- **레이아웃**: 3열 카드
- **각 카드 구성**: 아이콘 + 방법 + ❌ 한계
  - 카드 1: "반대 기사 추천" → "클릭 안 함"
  - 카드 2: "알고리즘 강제 노출" → "피로 + 이탈"
  - 카드 3: "악마의 변호인" → "설득 목적 = 반발"
- **하단 결론 텍스트**: "단순 노출이나 설득은 답이 아닙니다"
- **시각적 톤**: 각 카드에 희미한 ❌ 또는 회색 처리

### 대본
```
기존에도 시도가 있었습니다.
반대 기사를 옆에 추천하거나,
알고리즘으로 다양한 관점을 강제 노출하거나,
챗봇으로 반박하는 방식 등이요.

하지만 대부분 실패했습니다.
사용자는 관심 없는 건 클릭하지 않고,
강제 노출은 피로감만 주고,
설득은 오히려 반발을 부릅니다.
```

---

## 슬라이드 5: AcrossView 솔루션 (50초)

### 비주얼 디자인
- **상단**: "AcrossView의 접근" (큰 제목)
- **핵심 비주얼**: 기사 본문 목업
  - 특정 문장에 하이라이트 표시 (노란색 또는 브랜드 컬러)
  - 하이라이트 위에 작은 "+" 아이콘
- **하단 플로우 다이어그램** (3단계):
  ```
  [1] 쟁점 탐지 → [2] 하이라이트 표시 → [3] 클릭 시 다양한 관점 펼침
  ```
- **강조 문구**: "선택은 사용자에게, 접근성은 알고리즘이"
- **색상**: 깔끔한 화이트 배경 + 브랜드 액센트 컬러

### 대본
```
저희 AcrossView는 다르게 접근합니다.
반대 의견을 강요하지 않습니다.
대신, '다양한 관점으로 가는 문'을 만들어 둡니다.

핵심 기능은 '쟁점 하이라이팅'입니다.
기사를 읽다가 해석이 갈릴 수 있는 문장을 만나면,
알고리즘이 자동으로 하이라이트를 표시합니다.

중요한 건, 사용자가 클릭할지 말지 선택한다는 점입니다.
클릭하면 그 사안에 대한 다른 해석, 다른 관점,
객관적 팩트들이 펼쳐집니다.

알고리즘은 연결의 기회를 만들고,
최종 선택은 사용자가 합니다.
```

## 슬라이드 6: 데모 (1분 30초)

### 비주얼 디자인
- **풀스크린 데모 영상** 또는 **라이브 시연**
- 영상이 아닌 경우:
  - 큰 브라우저/앱 목업
  - 단계별 스크린샷 전환
- **좌하단**: 작은 "DEMO" 배지
- **영상 구성 권장**:
  1. (0-20초) 일반 뉴스 기사 화면
  2. (20-40초) 하이라이트 된 문장 발견
  3. (40-60초) 클릭 → 다양한 관점 카드 펼침
  4. (60-90초) 관련 기사 인용문과 출처 확인

### 대본
```
실제로 어떻게 작동하는지 보여드리겠습니다.

(데모 시작)

일반적인 뉴스 기사입니다.
읽다 보면 이렇게 하이라이트 된 부분이 보입니다.
이건 알고리즘이 "이 문장에 대해 다른 관점이 있다"고 알려주는 표시입니다.

클릭해볼까요?

보시는 것처럼, 같은 사안에 대한 다른 시각들이 나옵니다.
단순한 반대 의견이 아니라,
"누가, 왜 이런 관점을 가지는지"를 맥락과 함께 보여줍니다.

각 관점에는 실제 기사 인용문과 출처가 함께 제공됩니다.
사용자가 직접 확인하고 판단할 수 있도록요.

(데모 종료)
```

## 슬라이드 7: 기대효과 - 연결의 회복 (40초)

### 비주얼 디자인
- **상단 큰 텍스트**: "끊어진 연결을 다시 잇다"
- **중앙 3개 아이콘 + 텍스트**:
  - 🔗 **맥락 연결**: "상대가 왜 그렇게 생각하는지 이해의 실마리"
  - 💬 **대화 연결**: "공격 대신 질문, 승부 대신 이해"
  - 🤝 **사람 연결**: "상대도 논리가 있다는 인식"
- **하단 인용구**:
  > "연결은 설득이 아니라, 노출의 기회를 만드는 것에서 시작됩니다"
- **시각적 톤**: 따뜻한 느낌, 연결된 선/노드 그래픽

### 대본
```
저희가 기대하는 변화는 '연결의 회복'입니다.

첫째, 맥락 연결.
반대편이 뭘 근거로 말하는지 처음으로 이해의 실마리가 생깁니다.

둘째, 대화 연결.
바로 욕하거나 조롱하는 대신,
"왜 저렇게 생각하지?"라는 질문이 먼저 떠오릅니다.

셋째, 사람과 사람의 연결.
상대를 악으로 단정하는 대신,
"상대도 논리가 있다"는 인식이 생깁니다.

필터 버블을 깨는 방식은 설득이 아니라,
노출의 기회를 만드는 것입니다.
그 기회가 연결의 시작점이 됩니다.
```

## 슬라이드 8: 확장 가능성 + 마무리 (30초)

### 비주얼 디자인
- **상단**: 로드맵 간략 표시 (아이콘 + 한 줄)
  - Phase 1: 뉴스/웹 (현재)
  - Phase 2: 언론사/포털 B2B
  - Phase 3: SNS/영상 플랫폼
- **중앙 큰 텍스트**:
  > "이 서비스는 관점을 추천하지 않습니다.
  > 관점과 관점 사이를 **연결**합니다."
- **하단**: AcrossView 로고 + 팀명
- **QR코드** (선택): 데모 링크 또는 깃헙

### 대본
```
AcrossView는 뉴스에서 시작해,
언론사, 포털, 그리고 SNS까지 확장할 수 있습니다.

새로운 플랫폼을 만드는 게 아니라,
사람들이 이미 있는 곳에 연결의 레이어를 얹는 방식입니다.

저희가 만드는 것은 또 하나의 추천 서비스가 아닙니다.
관점과 관점 사이를 연결하는 플랫폼입니다.

감사합니다.
```

## 전체 톤 & 디자인 가이드라인

### 컬러 팔레트
| 용도 | 색상 | HEX |
|------|------|-----|
| Primary (연결) | 딥 블루 | #2563eb |
| Accent (하이라이트) | 웜 옐로우 | #fbbf24 |
| Background | 다크 네이비 | #1e293b |
| Text | 화이트/라이트 그레이 | #f8fafc |
| Warning/Conflict | 소프트 레드 | #ef4444 |

### 폰트
- **제목**: Pretendard Bold 또는 Noto Sans KR Bold
- **본문**: Pretendard Regular
- **영문 강조**: Inter 또는 SF Pro Display

### 비주얼 스타일
- 미니멀하고 깔끔한 디자인
- 아이콘은 선형(outline) 스타일 통일
- 그래프/플로우는 심플한 도형으로
- 각 슬라이드당 핵심 메시지 1개만

### 전환 효과
- 슬라이드 전환: 심플한 페이드 또는 슬라이드
- 요소 애니메이션: 순차적 나타남 (한 번에 모두 X)

## 발표 팁

1. **시간 관리**: 데모에 1분 30초 할당됨, 미리 연습 필수
2. **Hook 강조**: 첫 25초가 청중 집중도 결정
3. **"연결" 반복**: 해커톤 주제와 연결해 최소 3회 이상 언급
4. **데모 백업**: 영상이 안 되면 스크린샷 슬라이드로 대체
5. **마무리 임팩트**: 마지막 문장 ("관점과 관점을 연결합니다") 또박또박
